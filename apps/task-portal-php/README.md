# PHP портал заявок

## Запуск

```bash
cd apps/task-portal-php/public
php -S 0.0.0.0:8080
```

Откройте `http://localhost:8080`.

## Что входит
- Регистрация сотрудников с указанием руководителя.
- Постановка задач с автоматическим номером, вложениями и срочностью.
- Дашборд со статусами, кнопками принятия и расчетом стоимости.
- Формирование XLS и PDF отчетов по выполненным заявкам.
- Логирование писем в `apps/task-portal-php/storage/email.log`.

> В демо-режиме письма отправляются через `mail()` и всегда логируются в файл.
